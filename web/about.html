About la jbolaltci

This tool is inspired by the desire to have the definition-constructing feature in la jboski plus the "boxes" grammar-structure feature of la .ilmentufa while pulling in all of the new vocabulary available in la lidysisku / la lensisku.

It can be used as a web tool (available at https://alxndr.github.io/jbolaltci/) or as a JavaScript package jbolaltci.

The code is available on GitHub: @alxndr/jbolaltci
